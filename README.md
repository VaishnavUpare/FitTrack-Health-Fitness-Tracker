\# FitTrack - Health \& Fitness Tracker



FitTrack is a full-stack MERN health and fitness tracking application.



\## Features



\- User Registration and Login

\- JWT Authentication

\- Workout Tracking

\- Diet Tracking

\- Profile Management

\- Custom Fitness Goals

\- Calories and Macronutrient Tracking

\- Dashboard Analytics

\- Workout and Diet CRUD Operations

\- Progress Charts

\- Responsive Design



\## Tech Stack



\*\*Frontend:\*\* React.js, Axios, Chart.js, CSS



\*\*Backend:\*\* Node.js, Express.js



\*\*Database:\*\* MongoDB



\*\*Authentication:\*\* JWT and bcrypt
